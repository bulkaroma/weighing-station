    Help

    Connect on a Windows PC
    1. Disconnect the scale from any phone app. It can only connect to one device at a time.
    2. In Windows, open Settings → Bluetooth & devices → Add device → Bluetooth and pick the scale or adapter. The PIN is usually 1234 or 0000.
    3. Open More Bluetooth settings → COM Ports and note the Outgoing port, for example COM6.
    4. In Chrome or Edge, press Connect scale and choose Standard Serial over Bluetooth link (COM6).
    5. Next time, press Reconnect last scale.
    Connect on an Android phone
    1. Close any Bluetooth serial app that is connected to the scale.
    2. In Android Settings → Bluetooth, pair the scale or adapter. The PIN is usually 1234.
    3. Open this website in Chrome (keep Chrome updated) and tap Connect scale. Pick the scale and tap Connect.
    4. iPhone isn't supported, because Safari and other iPhone browsers can't use Bluetooth serial.
    Older scale with an RS-232 Bluetooth adapter
    1. Set the scale's RS-232 output to 9600 baud and continuous output in its menu.
    2. Switch the adapter to OFF, plug it into the scale's 9-pin port and power it with the USB cable.
    3. Slide the switch to SLAVE and press CLEAR once. Pair it as BOLUTEK or BC04-B with PIN 1234.
    4. Connect as above. If nothing arrives, press PRINT on the scale, choose a command under Ask the scale for the weight, or add a null-modem adapter between the scale and the adapter.
    Install as an app

    Android: in Chrome, tap ⋮ → Add to Home screen (or Install app).

    Windows: in Chrome or Edge, click the install icon at the right end of the address bar.

    Your log and formulas are stored on each device separately.

    Tips

    The scale's own TARE button zeroes the scale. The app's Tare only zeroes this screen, and Clear tare undoes it.

    Keyboard: Space records a weight or confirms an ingredient, Enter confirms an ingredient, and T tares.
